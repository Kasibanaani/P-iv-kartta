# Pakettipelin testit

`sh pakettipeli/testit/aja.sh` (repon juuresta). Poimii moottorin (`<script id="engine">`) tiedostoon `pp.js` ja ajaa:

- `logiikka_01_moottori.js`: kartan generointi (yhtenäisyys, determinismi), toimitus, kulut, auton osto ja myynti, täyden auton noutosääntö, reitin muokkaus, ennakkotilaus, peruuntuminen, ruuhkavuoto, maine-kerroin ja hinta, päivän lopetus, kaatuminen, tallennus ja korjaus sekä tasapaino botilla (1 auto 2/min pieni voitto, 8/min tappio).
- `selain_01_peli.js`: Chromium 390 px oikeilla napautuksilla (auto, nouto, tiepiste, järjestys, vastaanotto, osto ja myynti, päivän lopetus, valikko, teema, varmuuskopio, jatkuminen, kaatuminen) sekä 320 px asettelu. Kuvat: `tulosteet/`.
