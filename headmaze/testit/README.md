# Headmazen testit

Aja kaikki: `sh headmaze/testit/aja.sh` (repon juuresta). Vaatii Noden ja Playwrightin (Chromium).

- `logiikka_01_hengitys.js`: ajanotto ensimmäisestä painalluksesta viimeiseen irrotukseen, suhde, palkin piteneminen, tallennusmuodon korjaus, sokkelon rakenne.
- `selain_01_perus.js`: Hengitä oikeilla painalluksilla (kello siirretään testikoukulla `__hm.setClock`), tulos, tallennus, tilastot, varmuuskopio tekstinä, Minä-polku loppuun; 390 ja 320 px. Kuvat kansioon `tulosteet/`.

Testit ajetaan tietokoneen Chromiumissa, ei oikealla iPhonella.
