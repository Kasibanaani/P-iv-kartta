# Headmazen testit

Aja kaikki: `sh headmaze/testit/aja.sh` (repon juuresta). Vaatii Noden ja Playwrightin (Chromium).

- `logiikka_01_hengitys.js`: ajanotto, suhde, palkki elää käytön mukaan, vanhan version korjaus, repliikkipussi, Minä-polun rakenne.
- `logiikka_02_peli.js`: kartat (kaikkialle pääsee, huoneet ja aukot), näkeminen valokeilalla ja seinät, valokeilan reuna, ääni, takaa-ajo, kiinni jääminen, hukkaaminen ja eri aukot kahdelle hipalle, 60 hippaa × 2 min ilman jumiutumista.
- `selain_01_perus.js`: välilehdet, uloshengitys oikeilla painalluksilla (kello testikoukulla `__hm.setClock`), yhden ruudun asettelu ja alapalkki alareunassa, tilastot ja varmuuskopio, puhekuplan väkänen, Minä-polku loppuun (tauot nopeutettu), Sokkelo tatilla; 390 ja 320 px. Kuvat kansioon `tulosteet/`.

Testit ajetaan tietokoneen Chromiumissa, ei oikealla iPhonella.
